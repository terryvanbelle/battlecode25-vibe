# battlecode25-vibe

A [Battlecode 2025](https://battlecode.org) contest entry, developed under an
automated, evidence-driven iteration loop.

Sister project to
[`battlecode22-vibe`](https://github.com/terryvanbelle/battlecode22-vibe) and
[`battlecode26-vibe`](https://github.com/terryvanbelle/battlecode26-vibe).
`TRAINING_ALGORITHM.md` here is a fresh, year-agnostic synthesis of what those
two projects (~320 combined logged iterations) learned about how to run this
kind of loop — see their `LEARNINGS.md`, `RESEARCH.md`, and `TRAINING_LOG.md`
for the underlying record.

**Project ground rules:** no bot implementations downloaded from the web, and
no post-mortems from the current contest year. Prior-year post-mortems are
fair game.

| Path | What |
|------|------|
| `TRAINING_ALGORITHM.md` | the iterative dev-loop this project follows |
| `TRAINING_LOG.md` | running record of every iteration (starts with Iteration 0) |
